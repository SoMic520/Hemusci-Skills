Design Principles

专业技能的三条底线

技能的价值不在于写得更多，而在于能稳定约束判断、过程和交付。

01 / FACT

事实优先

不改写数值、类别、范围和结论方向，不为语言流畅编造数据、成因或验证提醒。

02 / DOMAIN

领域约束

术语、数量、尺度、证据和因果关系同时检查，不能用禁词清单代替专业判断。

03 / DELIVERY

真实交付

输出不仅是文字，还包括格式、修订记录、批注、图表关系、脚本校验和可归档文件。

Built to Grow

为下一个技能预留位置

仓库从第一天起就按多技能中心设计。新增技能有独立边界，也能共享统一的发布与安装体验。

后续方向

科研写作、自然资源调查、地学数据质检、图表生产、成果验收等技能可按同一规范持续加入。
