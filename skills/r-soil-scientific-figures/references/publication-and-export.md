## 先确定目标

记录期刊/出版社、文章类型、初投或终稿、单栏/双栏/整页、在线或印刷、RGB/CMYK、允许格式、像素/物理尺寸、字体、文件大小和是否要求独立面板。实时打开官方作者指南；不要把某出版社的通用规则自动套给旗下全部期刊。

没有目标时采用通用起点并标记为 provisional：

- 单栏约 85–90 mm，双栏约 175–180 mm；
- 正文型论文图以 PDF/SVG 为矢量主文件；影像/连续色调用 TIFF/PNG；
- 通用 profile 以最终尺寸下约 7.5 pt 为布局告警下限；如果标签密度要求继续缩小，应先改栏宽、分面、方向或换行；
- 白色或明确的不透明背景，除非版面确实要求透明。

这些不是合规保证。

当前官方要求说明了为什么不能写一个全局固定字号：Nature 主图当前采用 89/183 mm 宽、最大 170 mm 高，并要求最终文字 5–7 pt；Elsevier 通则给出 90/140/190 mm 参考宽度，普通文字 7 pt、上下标不小于 6 pt 只是经验规则，而且明确要求查看期刊专属指南。skill 因此先由成图物理尺寸、有效面板宽、分面数、类别数和最长标签计算字号，再由目标期刊 profile 设上下限；来源键为 `J-NATURE-FIGURES`、`P-ELSEVIER-ART`。

构建独立复现包时可显式选择：

```bash
python3 scripts/build_figure_bundle.py \
  --recipe raincloud-plot \
  --output outputs/raincloud-nature \
  --journal-profile nature \
  --width-mm 89 --height-mm 72 --execute
```

`generic`、`nature`、`elsevier` 是当前快照；`custom` 配合 `--min-size-pt` 和 `--max-size-pt` 用于目标期刊的实时要求。最终解析的 profile、上下限、基础字号、面板宽和密度惩罚进入 manifest。

## 尺寸与版式

- 先按毫米确定画布，再设置字体和线宽；不要先画巨大画布后任意缩小。
- 物理宽度固定时，面板数越多，可用文字/点空间越少。优先拆图而不是无限压缩。
- 1:1 parity、QQ、同单位空间或圆形几何使用等比例坐标；一般时间/梯度图不必方形。
- 共享尺度支持比较；free scales 只能在每面板的绝对比较不重要且明确标注时使用。
- 避免把图题放在画布内，除非载体需要自包含；论文上下文通常由图注和面板标题承担。
- Geoderma 当前指南明确要求图注中的简短标题不显示在图形本体内；技术 recipe 名、schema 名和测试状态应进入文件名、manifest 或图注，不应占用论文画布。

## 文字、线条与符号

- 使用目标期刊可接受且可嵌入的字体；不要假定 Times 是所有期刊唯一选择。
- 统一字体家族，但允许标题、轴、刻度和注释有有限层级；不要求所有文字同一字号。
- 中文轴标签默认采用 `指标名称/ (单位)`，例如 `土壤有机碳/ (g kg⁻¹)`：中文名称后紧接 `/`，斜线后留一个半角空格。
- 英文轴标签默认采用 `Variable / (unit)`，例如 `Soil organic carbon / (g kg⁻¹)`：斜线两侧各留一个半角空格。
- 中英文混排轴标题分别解析 CJK 与 Latin 字体片段，并保持正常字重；在 R 中可用 `ggtext::element_markdown()` 或等价 grob 实现，但必须在 PDF 与栅格输出中检查旋转、基线、上下标和字体回退。
- 复合英文单位默认用半角空格分隔，如 `g kg⁻¹`、`mg L⁻¹`、`kg N ha⁻¹`。只有目标期刊或领域规范明确要求时才改用居中点或其他乘法记号。
- 数学、单位和化学式使用正确字符/表达式，如 `kg N ha⁻¹`、`CO₂`、`δ¹³C`；避免把上下标写成 ASCII 文本。
- 无量纲指标通常只写指标名；百分数写成 `/ (%)`。pH、比值、对数、标准化量或模型尺度必须按科学定义标注，不能仅靠单位括号暗示变换。
- 标准数据表的响应变量列使用真实指标名，不把 `Value`、`测定值` 或 `数值` 作为正式表头；源表明确给出单位时，把单位按同一规则写入表头并与纵轴保持一致。源表没有单位时不猜测。
- Excel 输入表和统计表的列宽逐列以本列实际最长内容为基准并留少量边距；中文按全角宽度、英文和数字按半角宽度估算。极长内容达到最大列宽后自动换行，不让单个长表头无限拉宽整张表。
- 离散分类刻度已经清楚表达各组时，默认隐藏横轴总标题；只有用户要求或语义不清时才显示真实变量名。
- 若目标期刊要求 `Variable (unit)`、`Variable, unit` 或其他格式，以实时核对的官方指南为准，并在 manifest 记录轴标签样式。
- 物种学名按规范使用斜体；基因/蛋白、土类和分类名按领域规范。
- 在最终尺寸检查线宽、dash、点形和误差线端帽。不能只在 RStudio 放大窗口判断。
- 常规笛卡尔科研图默认用一个完整 `panel.border` 绘制上、下、左、右边框，并移除重复的左/下 `axis.line`，避免双线或粗细不一；顶部和右侧是否显示刻度要有比较目的，不随边框机械添加。网络、树、三角图、地图和示意图按语义例外处理。
- 点重叠时优先小点、透明度、蜂群/准随机、hexbin、二维密度或局部栅格化；记录改变后的统计含义。

## 颜色

按语义选择：

- 定性：无自然顺序的处理/土类/分类群；
- 顺序：低到高且单方向；
- 发散：有科学中心（零、无变化、基准）的正负偏离；
- 循环：坡向、风向、相位等首尾相接；
- 双变量：两个变量共同分级，必须配套二维图例且类别数低。

R 起点：`colorspace`、`viridisLite`、`scico`、`khroma`。不要把“色盲友好”理解为任何场景都可读；最终背景、字号、线宽、相邻颜色和印刷条件都会改变结果。颜色不是唯一线索。

连续色标默认保留连续映射。只有科学阈值、决策等级或读者任务需要时才分级，并列出断点。偏态分布不应自动改成分位数色阶而不说明，因为颜色距离将不再对应原始数值距离。

## R 设备与格式

推荐显式设备，不依赖 IDE 导出按钮：

```r
ggplot2::ggsave(
  filename = "outputs/figure-1.pdf",
  plot = figure,
  device = grDevices::cairo_pdf,
  width = 89,
  height = 70,
  units = "mm",
  bg = "white"
)

ggplot2::ggsave(
  filename = "outputs/figure-1.png",
  plot = figure,
  device = ragg::agg_png,
  width = 89,
  height = 70,
  units = "mm",
  dpi = 600,
  bg = "white"
)

ggplot2::ggsave(
  filename = "outputs/figure-1.tiff",
  plot = figure,
  device = ragg::agg_tiff,
  width = 89,
  height = 70,
  units = "mm",
  dpi = 600,
  compression = "lzw",
  bg = "white"
)
```

- PDF：线、点、文字和简单几何的首选；含大量点时文件可能膨胀。
- SVG：编辑和网页友好；字体可依赖系统，交付前检查文字是否保留/转路径。
- TIFF：许多期刊的终稿栅格格式；压缩、位深和颜色模式按官方规则。
- PNG：无损预览和屏幕输出；默认使用 600 dpi RGB、不透明白底。只有用户或目标载体明确要求时才额外导出透明版本，并在浅色与深色底上各检查一次。
- EPS：只在目标明确要求时使用；透明度和现代字体支持有限。
- DPI 对纯矢量线条/文字不是“分辨率”；它影响嵌入栅格和栅格输出。

`ragg` 提供稳定的栅格渲染，`svglite` 用于 SVG。复杂 Unicode/CJK/数学字体可用 `systemfonts`/`textshaping`/`showtext`，但必须检查嵌入和实际字形；不要仅因屏幕显示正常就假定投稿文件正常。

## 多面板

用 `patchwork` 的布局表达逻辑：

```r
figure <- (panel_a | panel_b) /
  panel_c +
  patchwork::plot_layout(guides = "collect") +
  patchwork::plot_annotation(tag_levels = "A")
```

- 公共图例仅在 aesthetics、limits、breaks、labels 和 units 完全一致时收集。
- 地图、热图和普通 ggplot 对象的 grob 对齐可能不同；在最终设备中检查。
- 领域对象（`ComplexHeatmap`、base graphics、`aqp`）不一定是 ggplot，必要时用原生 grid 布局或先生成独立面板，不强行转化导致裁切。
- 面板标签与稿件引用一致；附图/主图分别编号。

## 交付包

用户要求“只要代码、代码所需表格和生成图”时，单图文件夹只保留：

```text
图形名称/
├── 图形名称.R
├── 图形名称_中文注释版.R
├── 标准输入表格.xlsx
├── 图形名称.pdf
├── 图形名称.png
├── 图形名称.tiff
└── 图形名称_中文注释.txt
```

不得附加 README、config、`data/`、`lib/`、`outputs/`、`statistics/`、checksums、运行脚本、单独安装脚本、manifest、session-info 或 QA 中间文件，除非用户明确要求完整审计工程。默认拒绝无提示覆盖现有正式输出；使用版本化文件名或取得明确覆盖授权。

标准运行表只包含代码实际读取的数据；中文图注以一段完整中文定义面板、处理/组、观测/估计层、实验单位与 `n`、误差/区间、模型/检验、调整方法、阈值、颜色/符号、缩写、空间/影像处理和必要数据来源。

## 视觉核验

1. 用 `pdfinfo`/图像元数据工具检查页面/像素尺寸、颜色、页数和文件大小。
2. 用 Poppler 等将 PDF 按最终物理尺寸附近渲染为 PNG。
3. 查看完整图和 100% 局部；对 CJK、希腊字母、上下标、负号、乘号和物种名重点检查。
4. 与输入数据做数量/范围/汇总交叉核验；抽查点和分组映射。
5. 以灰度、常见色觉模拟和低质量打印作为筛查，不把任一筛查当完整可访问性认证。
6. 将图放入真实稿件版心再看，不在独立大图上验收。
7. 最后一次核对期刊官方页面，记录访问日期和适用阶段。
