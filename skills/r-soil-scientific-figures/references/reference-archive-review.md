# 四个用户参考压缩包的吸收范围

此文件只记录结构化审计结论。参考包中的脚本、数据、成图、宣传文字和水印不随 skill 再分发，也不作为科学方法或期刊规范的权威来源。论文方法、包接口和期刊规则仍以原始论文、CRAN/Bioconductor 官方文档及期刊官网为准。

## 已进入独立实现的设计原则

1. 复合图不再退化为单一散点或折线。树—热图、分类树—丰度条、热树、排序图、Mantel 图、地图嵌套和分布—估计组合必须有独立输入契约和渲染分支。
2. 原始点、分布、估计量和不确定性分层绘制。显著性只读取已验证分析结果；模板不替用户发明检验、字母或星号。
3. 组合图在 R 内完成对齐和导出，不依赖“导出后再到 AI/PS 手工拼接”才能得到最终版。
4. 树、样本、热图和注释轨按显式键对齐；不得按当前行序猜测。
5. Mantel、排序、环境拟合、相关网络和微生物组图必须记录距离、变换、置换限制、阈值和多重检验。
6. 环形布局只在周期、层级或多轨对齐确有意义时使用；不会把普通柱状图机械弯成圆形。
7. 参考图中的颜色只作为布局观察，不复制特定商业模板的视觉资产；交付使用独立、色觉友好的语义色板。

## 明确不继承的写法

结构审计发现参考脚本中有大量 `setwd()`、Windows 绝对路径、运行时装包、固定字号、图内标题、手工显著性、双轴和导出后再手工修图。它们不直接进入交付代码。

- 输入输出全部相对 bundle 根目录解析；macOS 与 Windows 使用同一入口。
- 安装依赖与绘图运行分离；缺包检查可选择自动安装，但绘图脚本本身不修改环境。
- 字号按最终物理尺寸、面板宽度、标签密度和分面数计算，并执行可读下限。
- 内部标题和内部长图注默认关闭；题名与完整图注留给论文排版。
- 随机布局、抽样和置换必须设置并记录随机种子。
- 双轴只在存在明确、可逆且有科学含义的换算时允许，并在图注记录转换。

## 复核方式

四个包解压在临时审计目录，所有 PNG 和扩增子 PDF 首页均生成联系表做人工视觉复核。最终 skill 只保留汇总、实现对照和独立测试结果，不保留参考图或参考代码副本。
