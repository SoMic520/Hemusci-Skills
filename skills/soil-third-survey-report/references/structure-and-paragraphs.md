# 标题、段落与小节组织

## 1. 基本尺度

篇幅统计采用接受修订后的正文有效文字，不含封面、目录、图表内文字、图表题注、页眉页脚和附件。县级总体报告一般3000—5000字，县级工作报告正文不超过15000字；市级总体报告一般7000—8000字，市级工作报告一般15000—20000字；省级土壤资源评价与利用综合报告一般30000—50000字，其他省级报告按现行导引、模板或用户要求执行。具体任务由用户另行指定时优先执行。

### 1.1 单段字数

- 分析性正文通常控制在500—1000个汉字，不含标题、题注、公式和表内文字。
- 段落数量增加时，单段长度可以相应减少。承担完整数据分析和专业解释的主体段原则上不少于300字；短方法说明、定义、过渡、表图引导和小节结语不适用该下限。
- 三级小节安排3段时，每段宜为500—1000字；安排4段时，每段宜为400—800字；安排5段时，每段宜为300—650字。
- 四级小节安排2段时，每段宜为500—900字；安排3—4段时，每段宜为300—700字。
- 章首导语、承上启下句和小节结语可短于300字，但不得冒充分析性正文计入规定段数。
- 连续出现两个不足300字的主体分析段时，先检查两段是否承担不同功能；功能重复时合并，证据充足但展开不足时补足数据、比较和专业解释。不得仅为达到字数增加常识、背景或套话。
- 超过1000字的段落先按论证功能拆分，不按句数或版面长度机械截断。
- 同一段只承担一个主论点，可包含相互支撑的数据、比较和解释，不混入第二个独立主题。
- 修订既有报告时，单段接受修订后的净增减原则上不超过100字；纠正严重逻辑错误、拆分超长段落、删除重复套话或按用户要求扩充数据分析时除外。拆分后的相关段合并计算净增减，避免用形式拆段规避限制。
- 全文接受修订后的有效字数原则上不得少于原稿，除非用户明确要求压缩。该要求不得阻止删除重复、错误或AI套话；确需删除时，应以同节中更准确的数据叙述和专业分析补足，而不是逐句等量填充。

### 1.2 每小节段落数

按标题层级控制正文体量：

- 实质性三级小节通常组织3—5个正文段落。单一主题以3—4段为宜；确有“总体结果、区域差异、地类差异、成因、措施”五个独立论证环节时可写5段。方法说明、数据来源、定义、结果校验和简短小结可以少于3段，但必须完整回答该标题承载的任务。
- 四级小节通常组织2—4个正文段落。内容不足2段时优先并入相邻四级小节，内容超过4段时检查是否包含两个独立专业主题。
- 二级小节若直接承载正文而不设三级标题，通常组织3—5段；若下设三级标题，二级标题后只写1段不超过300字的导语，具体内容放入三级小节。

三级小节的3—5段通常承担：

1. 第一段：交代评价对象、指标范围、时间或空间基准，并给出本级区域总体结果。
2. 第二段：列示下辖行政单元、地类、土类、母质、地形部位或等级之间的主要差异，以数据支撑。
3. 第三段：解释差异所反映的土壤过程、形成条件或利用管理特征，严格控制因果强度。
4. 第四段：在数据充分时归纳农业利用、土壤改良、监测管护或成果应用意义。

三段式适用于“范围和总体结果—空间差异—专业解释”已经完整的单一主题。四段式适用于同时包含现状、差异、成因和措施的综合主题。五段式只在两类差异需要分别展开，或需要独立设置成果应用段时使用。不得为了满足段数重复同一结论。

表题、图题、表后注释、图后注释、公式、项目列表和仅含引用关系的短句不计入3—4段。章首总述不作为下属小节的第一段。

### 1.3 材料不足或过多时

- 三级小节只有1—2段材料：先判断该小节是否应并入相邻主题；不能用空话扩成3—5段。
- 三级小节超过5段且包含两个以上独立专业对象：判断是否需要设置合适的下级标题。
- 三级小节超过5段但仍围绕同一对象：合并重复数据和同义解释，保留3—5个功能清楚的段落。

段数和单段字数均服从报告总篇幅。县级总体报告等短篇成果不得因三级小节数量较多而机械套用“每节至少3段、每段至少300字”。当结构目标与总字数冲突时，优先保留关键数据、主要空间差异和专业结论，合并次要内容或减少不必要的下级标题。
- 单个小标题下出现数千字连续正文：先识别其中已具标题功能的正文短句，再决定恢复标题样式、重新命名或拆分。
- 新增下级标题必须与上位标题形成从属关系；标题层级不匹配时宁可重命名，也不只为缩短页面而新增。默认不得越过“（一）”层级；已有“1.”时重点审查其必要性和并列性。

## 2. 标题层级

按用户或验收导引规定执行。没有另行规定时，只使用：

- 一级标题：`一、……`
- 二级标题：`（一）……`

默认结构到二级标题为止，不照搬旧导引中的深层标题。原稿已经存在`1. ……`时，将其视为需要专门检查的三级标题：确认它是否确有两个以上并列内容、是否与上位标题形成从属关系、是否需要保留或重命名。只有原稿或用户明确要求时才使用`（1）……`及更深层级。

审查既有报告时优先保留原有一、二级标题。用户明确要求“不改标题”或“一二级标题不改”时，不得修改其文字、编号、顺序、样式或目录层级。用户点名保留的重复编号也应保留，并在任务记录中注明，不得擅自纠正。

### 2.1 标题命名规则

- 用“专业对象＋分析内容”命名，如“土壤酸化程度及空间分布”“不同地类有效磷不足特征”。
- 方法、结果、成因和措施需要并列时，保持同一层级语法一致。
- 不用“有关情况”“相关内容”“其他问题”“分析结果”等无法区分主题的标题。
- 不用完整结论句充当标题，除非全章采用结论式标题且用户认可。
- 不在标题中使用“应该”“需要”“建议”等审稿口吻。
- 不新增与上位标题同义的下级标题，例如在“土壤酸化”下再设“土壤酸化情况”。
- 同一上位标题下原则上至少有两个同级子标题；只有一个时，应评估取消该层。

### 2.2 正文格式中的隐性标题

遇到以下情形，判断其是否为遗漏样式的标题：

- 独立成段且长度通常少于30字。
- 无句号，使用名词性短语。
- 后文连续若干段围绕该短语展开。
- 与前后相邻标题具有并列关系。
- 在目录或旧稿结构中能找到对应条目。

不能只凭字体加粗判定。先核对上下文、编号和目录，再恢复标题样式或重新命名。

## 3. 段落功能模板

### 3.1 现状与空间分布小节

组织3—4段：

1. 说明评价面积、样点或指标，并给出本级区域的等级面积、比例或均值。
2. 比较下辖行政单元或主要地类的高值、低值和集中分布区。
3. 联系母质、地形、水热、植被或土地利用解释空间差异。
4. 归纳主要限制区域和利用管理意义；若无新增信息，可省略第四段。

### 3.2 历史变化小节

组织3—4段：

1. 说明比较时期、共同评价范围和变化指标。
2. 给出总体增加、下降、稳定或等级转移数据。
3. 分析不同下辖行政单元、地类或土类的变化差异及主要来源去向。
4. 解释变化与利用方式、投入管理、生态恢复或环境条件的联系。

不得把现状面积图与跨期转移图写成同一类证据。现状图回答“现在分布在哪里、占多少”，转移图回答“从何种等级转入、向何种等级转出”。

### 3.3 成因分析小节

组织3—4段：

1. 从数据中明确主要现象和区域，不先写泛化原因。
2. 分析自然因素，如母质、地形、水热、淋溶、侵蚀和植被。
3. 分析人为因素，如耕作制度、施肥、灌排、土地利用变化和工程扰动。
4. 综合说明各因素的相对作用及适用范围，不把相关性写成唯一因果。

### 3.4 改良利用与对策小节

组织3—4段：

1. 明确需改良的土壤类型、等级、区域和主要限制因子。
2. 提出与限制因子对应的农艺、工程或生态措施，并写明适用地类。
3. 说明实施顺序、关键条件、投入方向或监测指标。
4. 归纳下辖行政单元之间的差异化安排和预期改善对象，不作没有数据依据的成效承诺。

### 3.5 方法与制图小节

组织3—4段：

1. 说明数据来源、样点、尺度和指标处理边界。
2. 说明模型、分级或制图方法及关键参数。
3. 说明成果精度、空间表达和图件组成。
4. 说明成果适用尺度和使用范围，不写“仍需验证”等笼统免责语。

### 3.6 工作组织小节

组织3—4段：

1. 说明组织体系和职责分工。
2. 说明实施过程、队伍配置和时间安排。
3. 说明质量控制、技术指导和档案管理。
4. 说明形成成果和应用情况，使用具体数量或事实。

## 4. 句群组织

每段内部优先采用：主题句—数据句—比较句—解释句—归纳句。主题句只界定本段内容，不使用空泛导语。数据句给出2—5个最能支撑结论的数字；更多数字交给表格。比较句明确比较对象和基准。解释句使用土壤过程和当地条件。归纳句收束本段，不重复标题。

避免每句都以“同时”“此外”“进一步”“总体来看”开头。连接关系应由对象和逻辑自然形成。
