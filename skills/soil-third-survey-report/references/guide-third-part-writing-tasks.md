# 省市级导引第三部分写作任务

本文件依据《第三次全国土壤普查省市级成果清单及编制导引》第三部分提炼，重点细化市级报告“各部分应写什么、依据什么写、怎样形成结果和结论”。省级任务在使用本文件前，必须结合[省、市、县三级成果层级规则与验收差异](province-city-county-levels.md)转换为跨市校核和全省综合；县级任务以县级验收导引和该层级规则为准。本文只学习内容任务和表达方法，不照搬原提纲的标题层级。

## 1. 使用边界

- 新写报告默认只设置到`一、`和`（一）`层级。
- 原稿已有`1.`层级时，检查其必要性、并列性和命名，不得遗漏。
- 不因导引示例中出现深层编号而机械增加`1.`、`（1）`等标题。
- 土壤农业利用适宜性、土壤酸化和土壤有机质的旧提纲只提供分析思路，结构可按现有成果、区域特点和读者需要重组。
- 导引给出的表格是信息任务示例，不是必须原样复刻的固定表式。
- 县级报告不得直接套用“县级成果汇总、县际比较、市级接边”等市级任务；省级报告不得仅把“全市”替换为“全省”。
- 用户提供的最新验收要求、技术规范和原稿结构优先。

## 2. 各模型通用写作协议

任何语言模型撰写前，先建立“内容任务矩阵”，每个结构项至少填写：

| 字段 | 要求 |
|---|---|
| 写作对象 | 本节具体回答的土壤、区域、地类、指标或工作环节 |
| 数据来源 | 外业调查、内业检测、制图成果、历史资料、工作档案或专题成果 |
| 评价范围 | 本级行政区域、下辖行政单元、地类、土类、共同评价区或样点总体 |
| 必写数据 | 面积、比例、均值、等级、样点数、变化量、精度或完成数量 |
| 比较维度 | 下辖行政单元、地类、土类、母质、地形、时期或等级 |
| 专业解释 | 成土过程、自然条件、利用管理、生产投入或工程条件 |
| 结论形式 | 现状判断、空间分异、变化趋势、限制因子或改良方向 |
| 对应表图 | 支撑本节的表号、图号及其独立功能 |

矩阵未完成前不得直接生成大段正文。写作时把每一行转换为3—5个有不同功能的段落，而不是把字段名称写成标题。

## 3. 总体报告应写什么

本节针对市级总体报告，正文一般严格控制在7000—8000字。它是全市成果的高度综合，不是各专题报告的拼接。每类成果只保留最能代表全市特征的关键数据、主要空间差异、核心专业结论和应用价值。县级、省级总体报告的篇幅和汇总尺度按层级规则执行。

### 3.1 开篇总述

交代普查依据、时间、组织方式、动员力量、范围与任务、投入、形成成果和已开展的生产应用。只写能够由工作档案和成果清单支撑的事实。

### 3.2 工作概况

汇总市级及所辖县级任务完成情况，重点说明组织、质量控制、关键工作数量和形成成果。不要把工作过程逐日记流水账。

### 3.3 成果概述

从各专题报告提炼：

- 主要土壤类型、分布和与二普相比的变化及原因。
- 主要物理、化学和养分性状，历史变化及退化障碍。
- 耕地、园地、林地、草地利用现状与土壤适宜性结果之间的匹配情况。
- 特色农产品生境、土壤条件和适宜分布区。
- 高、中、低等级耕地面积、分布和主要障碍。
- 当地实际存在的酸化、盐渍化、瘠薄、板结等专题成果；不存在的类型不写。
- 土壤生物、有机质等其他专题成果及其生产应用价值。
- 数据库、样本库、土壤志、土种志和档案成果。

每类成果以“关键数据—主要空间特征—专业结论—应用价值”组织，不写成果名称清单后即结束。

### 3.4 应用建议

从前文问题推出建议：

- 根据理化性状和基础设施提出培肥、障碍改良和耕地质量提升方向。
- 根据农业利用适宜性和特色农产品适宜性提出产业布局和结构调整方向。
- 根据不同土壤、作物和环境提出因土适种、因土施肥和资源保护措施。
- 根据已有数据平台与管理需求提出数据应用方式。

每项建议写清区域、对象、限制因子、措施和监测指标，不写通用口号。

### 3.5 应用成效

只写已经实施的案例。写明应用主体、地点、成果类型、应用范围、实施时间和效果。计划开展的事项放入建议，不包装成成效。

## 4. 工作报告应写什么

本节针对市级工作报告，正文一般严格控制在15000—20000字。篇幅主要用于完整交代组织实施、任务完成、质量控制、成果形成、应用成效和工作成效；不得以大段背景意义或重复附件清单填充字数。县级工作报告正文不超过15000字，省级工作报告按现行导引、模板或用户要求执行。

### 4.1 背景与目标

结合当地自然、社会经济和农业农村发展情况说明为什么开展普查、主要任务是什么、对当地有什么具体作用。避免照抄国家层面的意义表述。

### 4.2 组织实施

分别写清：

- 领导机构、办公室、技术支撑、采样、检测、质控和成果编制单位及职责。
- 实施方案、经费方案、质量控制方案的编制和评审。
- 外业、内业、质控和成果队伍的人员数量、培训和管理。
- 专家指导、咨询答疑和技术服务的次数、对象和解决事项。
- 宣传渠道、数量和覆盖对象。
- 经费落实、使用、安全和保密。

材料来自成立文件、招标文件、方案、培训记录、专家意见、媒体记录和经费档案。

### 4.3 任务实施

按工作环节写事实：

- 普查行政范围、地类、面积和起止时间。
- 底图类型、年份、比例尺、坐标系、来源和编制单位。
- 下发样点、校核方法、调整数量、原因、单位和人员。
- 表层样、剖面样、特殊样品和标本的数量、时间、机构和参与人员。
- 样品接收、风干、制备、检测的承担单位、数量、指标和项次。
- 外业、内业、阶段验收和平台审核的质控措施、项次、合格率、问题和整改结果。
- 成果编制队伍、成果名称、类型、编制单位、负责人和形成过程。

正文概括关键做法和数量，详细清单放表格或附件。

### 4.4 工作成效

说明普查实际查清了什么、形成哪些优化利用对策、培养了哪些队伍、提高了哪些业务能力、形成哪些公众传播效果。问题与建议分别面向组织实施、成果应用和数据档案管理，不与技术报告的土壤问题混写。

## 5. 土壤资源评价与利用综合报告应写什么

### 5.1 普查概述

说明区域地理区位、面积、行政区、气候、地形、水系、土地利用、人口经济和农业生产；说明普查时间、对象、地类、样点、工作程序、技术方法、数据来源与成果清单。

背景材料只保留与土壤形成、资源利用和农业生产有关的内容。每个自然或社会指标都应说明其与土壤资源的联系。

### 5.2 自然条件与社会经济

- 气候：类型、温度、积温、日照、无霜期、降水、蒸发、灾害及区域梯度，重点联系农业生产和土壤水热过程。
- 母岩母质：类型、面积和分布，联系土壤类型、质地、酸碱和养分来源。
- 地形地貌：类型、面积、海拔和分布，联系侵蚀、淋溶、土地利用和土壤类型。
- 植被：自然与人工植被、园林草地类别、优势植物和耕作制度。
- 水资源：地表水与地下水数量、质量、利用条件和农业限制。
- 社会经济：经济布局、产业、人口劳动力中与土壤利用和演变有关的内容。
- 土地利用：现状面积和空间分布；追溯二普或历次国土调查以来的农用地变化及原因。
- 农业生产：基础设施、灌排、农田建设、耕作制度、作物、投入和产量的现状与变化。

### 5.3 土壤类型与制图

写清分类依据、命名规则、各级类型数量、二普与三普类型对照和历史沿革。类型分布部分依发生分类顺序说明类型、面积、分布、性状和利用，不在综合报告中堆入所有典型剖面。

类型变化区分三类来源：分类规则变化、旧分类订正、自然或人为作用引起的实际性状和类型变化。历史沿革重点说明前两类，变化分析重点说明第三类，并提供空间和数据依据。

制图部分写明技术路线、县级图收集校核、相邻县接边、市级综合。接边问题和处理结果属于方法与质量说明，不写成土壤分布结论。

### 5.4 土壤属性与制图

属性类别包括物理性质、化学性质、有机质与氮磷钾、中微量元素、特殊元素和属性间联系。根据当地农业生产和土壤特点选择重点，不要求每个指标同等篇幅。

每项重点属性至少从以下维度展开：

1. 全市总体：样点统计与制图统计的等级、均值、中位值、范围、面积和比例。
2. 土地利用差异：耕地、园地、林地、草地及必要的二级地类差异和原因。
3. 土壤类型差异：按土类、亚类或土属比较，并用发生学解释。
4. 成土环境差异：仅对确有联系的母质、地形、水热或植被因素开展比较。
5. 历史变化：在共同评价基础上比较二普、测土配方施肥和三普结果，联系土地利用、耕作、施肥、农田建设等解释。
6. 区县差异：比较各县均值、等级面积、单项丰缺和多项联合特征。
7. 改良利用：由属性限制直接提出对象明确的措施。

属性制图写环境变量筛选、模型、参数、精度、县级成果衔接和市级图形成。文字不简单复述表格，也不逐像元描述。

有机质专题只借用上述“总体—地类—土类—成土环境—历史变化—应用”思路，章节可自由重组。

### 5.5 土壤退化、障碍与改良

先按当地实际确定类型，再对每类写资料基础、现状与空间分布、历史变化、成因、已有治理及改良利用。没有盐渍化时不设置盐渍化章节。

酸化专题只借用以下分析任务，不照搬旧结构：

- 交代样点、历史数据、pH和环境变量来源。
- 说明pH现状、酸化变化量、样点、面积、比例、等级和空间分布。
- 比较二普、测土配方施肥时期和三普的共同评价结果。
- 比较耕地、园地和其他地类的酸化特征、理化性状和肥力。
- 从降水淋溶、母质缓冲、施肥、种植制度、作物带出和土地利用变化解释。
- 说明已有治理措施、区域、规模和实际成效。
- 对不同酸化等级及水田、旱地、园地提出差异化措施。

### 5.6 耕地质量等级

写明县级成果校核、市级汇总与制图方法。结果分析至少包括全市平均等级和高、中、低等级面积，各县等级与限制因素，主要土壤类型的耕地质量，以及各等级的立地条件、理化性状、养分、农田管理和产能。

问题部分给出障碍类型、区域、面积、程度和对生产的影响；原因部分使用外业与内业数据；建议按区域和问题给出可操作技术，不机械追求政策、管理、技术三类套话。

### 5.7 土壤农业利用适宜性

该导引结构视为过时，只参考下列写作思路：

- 说明评价对象、现状地类和评价结果的范围。
- 给出宜耕、宜园、宜林、宜草及不适宜的面积和程度。
- 比较现状利用与适宜性结果，重点解释匹配和不匹配区域。
- 分析主要限制因子、土壤类型差异和空间分布。
- 讨论宜耕潜力时扣除现状耕地，并同时考虑生态保护、坡度、水源和开发条件。
- 布局建议同时服务耕地保护、农用地优化、土壤改良和农业生产。

可根据实际成果重新组织为“评价基础—总体格局—匹配关系—限制因素—分区利用”，不受旧提纲标题约束。

### 5.8 特色农产品土壤适宜性

写生产概况，包括类型、品质、种植历史、区域、面积、产量、品牌和规划；分产品汇总县级评价，分析影响特色品质形成的土壤环境组合；跨县或市级主导产品采用统一评价基础。

布局建议比较现状种植与适宜区差异，区分保护、稳定、调整和潜在发展空间。产业建议可以涉及土壤培育、栽培、种质保护、田间基础设施、技术推广和产业条件，但土壤适宜性不能直接替代市场、交通和生态可行性判断。

### 5.9 综合利用建议

综合前述土壤类型、属性、退化障碍、耕地质量和适宜性结果，按区域特色提出土壤利用分区、培肥改良和保护建议。每条建议必须能追溯到前文数据或结论。

## 6. 土壤志与土种志应写什么

### 6.1 土壤志

重点写结果和结论，方法与数据来源简述。内容包括区域概况、成土过程、分类与分布、各土类和亚类、理化性状、资源评价利用、改良保护及建议。

各土类说明分布区域、类型特征、利用与改良；各亚类下说明所含土属；各土属重点写分类归属、分布、性状、利用和改良。不要把综合报告原文整段复制到土壤志。

### 6.2 土种志

以土种为基本单元，覆盖各县主要土种。每个土种写分类归属、跨县分布、主要性状变幅、代表性典型剖面和利用性能。典型剖面应从多县资料中选择代表性和完整性较好的对象。

## 7. 数据报告应写什么

围绕“有什么、哪里来、有多少、存哪里、如何用、如何管”组织：

- 县级汇交数据和市级整合数据的类型、格式、时点、数量、存储量、比例尺、分辨率、坐标系和投影。
- 数据集成、异常标记和成果编制数据集的形成。
- 公共数据的统一使用范围，如行政区和土地利用面积。
- 各成果实际使用的数据及处理结果。
- 按县、地类、土类统计外业和内业关键指标的极值、均值、中位数和区间分布。
- 按县、地类、土类统计成果面积和等级。
- 存储设备、存储方式、数据库、系统功能、管理制度和数据安全。

该报告写数据全流程事实，不展开土壤成因和农业对策。

## 8. 档案成果应写什么

系统收集市级组织、队伍、实施、成果应用、宣传指导等原始工作资料，以及数据、图件和报告成果。按档案规则分类、编目、成册，说明保管主体和使用范围。正文不把档案目录改写为工作成效。

## 9. 由导引提炼的表达方式

### 9.1 先交代依据，再给结果

用“依据外业调查、内业检测和属性制图结果”限定证据来源，随后直接给出数据和空间结论。方法说明只写到理解结果所需的程度。

### 9.2 表格负责完整，正文负责判断

表格保存全部分类和数值，正文选择全市总体、主要等级、显著区域差异和具有土壤学意义的现象。不要逐格复述，也不要只写“见表”。

### 9.3 比较必须落地

比较区县、地类、土类、母质或时期时，至少给出比较对象、基准、方向、幅度和区域。结论后解释与当地自然条件和利用管理的联系。

### 9.4 成因必须承接现象

先写现象及空间差异，再写成土环境或人为因素。不能把“降水、母质、施肥、耕作”作为所有地区通用的原因清单。

### 9.5 建议必须回扣限制因子

建议写成“在何地、针对何种土壤或地类、解决什么限制、采取什么措施、监测什么指标”。不写脱离评价结果的产业口号。

## 10. 模型自检问题

生成每个小节后逐项回答：

1. 本节是否明确说明了分析对象和评价范围？
2. 是否至少有一个可核对的数据事实？
3. 是否比较了最有意义的空间、地类、土类或时期差异？
4. 专业解释是否由前述现象引出？
5. 是否把表图信息转化成了读者可理解的结论？
6. 是否出现“以表为准”“需要验证”“不可混用”等审稿提示？
7. 是否出现与当地实际无关的退化类型或措施？
8. 建议是否能追溯到本节或前文结果？
9. 标题是否只到必要层级，是否错误照搬旧提纲？
10. 接受修订后的正文是否可直接提交专家评审？
