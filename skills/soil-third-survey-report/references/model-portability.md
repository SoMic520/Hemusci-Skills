# 模型无关执行说明

本技能的专业写作规则不依赖Codex。DeepSeek、通义、Kimi、Claude或其他能够读取本地文件、知识库或系统提示的模型，均可按以下方式加载。

## 1. 加载顺序

1. 把`SKILL.md`作为主系统指令或最高优先级知识文件。
2. 把`references/province-city-county-levels.md`、`guide-third-part-writing-tasks.md`、`structure-and-paragraphs.md`、`formal-language.md`、`domain-and-acceptance.md`作为必读专业规则。
3. 只要任务涉及DOCX创建、重排、修订或终检，就必须加载`report-format-requirements.md`，并把它作为强制排版基准；不得只在用户提到“排版”时才加载。
4. 涉及数据和图表时加载`data-tables-figures.md`。
5. 只有用户明确要求了解或按NY/T 4980—2025核查土壤属性分级，或项目文件明确指定该标准并要求符合性检查时，才加载`soil-attribute-classification-nyt4980-2025.md`；不得默认加载后据此修改地方或项目分级。
6. 涉及DOCX修订时加载`docx-redline-workflow.md`。
7. 把用户当前报告、验收导引和特殊限制置于上述通用规则之前。

平台不支持自动读取引用文件时，把主技能和本次任务所需的参考文件合并放入知识库或长系统提示中。不要只加载`SKILL.md`后忽略其必读引用。

## 2. 模型执行契约

任何模型都必须：

- 从用户指定原稿开始，不在模型先前生成的修订稿上继续叠加。
- 先判定报告属于省级、市级还是县级，再确定汇总单元、比较尺度、篇幅和验收重点；不得只替换行政区名称。
- 先提取标题、段落、表格、图件和用户限制，再修改。
- 先建立每小节的内容任务和数据依据，再生成正文。
- 逐段处理，保留原稿事实、数值、单位、区域和结论方向。
- 语言审查必须同时覆盖土壤术语搭配、数量关系、分母与评价范围、空间尺度、时间趋势、证据强度、因果边界、句法和报告类型语体，不得以通过禁词扫描代替逐句专业判断。
- 把审查意见放在批注或审查记录，不写入正式正文。
- 不编造数据，不写“还需验证”等与用户确认相冲突的免责句。
- 不使用管理学词语、宣传口号和AI模板化升华。
- NY/T 4980—2025的属性分级只作提醒，不属于默认审查和修订范围；其他专题报告不得套用，属性报告也以项目实际采用的标准为准。
- 新写结构默认只到`（一）`；原稿有`1.`时必须识别并审查。
- 实质性三级小节通常3—5段；主体分析段原则上不少于300字。方法说明、定义、过渡和小结可短于该长度，不得为满足段数或字数机械扩写。
- 按层级控制篇幅：县级总体报告3000—5000字、县级工作报告正文不超过15000字；市级总体报告7000—8000字、市级工作报告15000—20000字；省级土壤资源评价与利用综合报告30000—50000字，其他省级报告按现行导引、模板或用户要求执行。
- DOCX必须执行强制排版基准：页顶距1.5厘米、页底距1.75厘米，前置部分用大写罗马数字页码，正文从阿拉伯数字1开始。
- 封面不得进入标题层级；标题1—标题5必须与`第一章`、`一、`、`（一）`、`1.`、`（1）`正确对应，`1.`后保留一个半角空格。
- `①`—`⑳`等带圈序号后必须保留一个半角空格。除明确要求保留的中文单位外，数量值一般使用规范单位符号；面积、体积、组合单位、化学式和离子必须正确设置上下标。
- 数值精度服从用户要求和正式导引：`亩`一律保留整数，`万亩`保留2位小数；其他指标没有更具体规定时，凡采用小数表达的数值统一保留2位小数，计数值和明确要求使用整数的指标保留整数；同类值的小数位数和末尾`0`保持一致。
- 必须建立可更新的正文目录、图目录和表目录；图题、表题使用“题注”样式及彼此独立的真实自动编号域，章号取自实际章节或正式模板，不得硬编码第五章。
- 图表说明段必须位于对应图表之前，图号或表号嵌入第一条实质性结果句并通常置于句末；说明段后空一行，完整图表块末尾（含最后一条表注或图注）后再空一行。图片—图题—图注、表题—表格—表注分别按完整块排布；若机械保持同页造成大面积空白，应在同一小节内调整图表与说明段位置或分页属性，使其仍紧邻主要描述分析段。用户指定保持不动的任意附图均保留内容、尺寸和页面布局。例如附图5.44—5.49只是示例，其他章和编号按同一规则类推。
- 表格使用版心100%宽度、自然行高、重复表头和通用黑色单实线；只加粗表头，清除底纹、多余空段和叠加粗线。
- 终检前清理未使用样式，同时保留全部已使用样式和依赖链；不得破坏脚注、超链接、修订、字段或特殊对象。
- 完成后分别检查接受修订后的正文和显示修订的版面。
- DOCX任务开始前运行`scripts/ensure_libreoffice.ps1`。未找到LibreOffice时自动安装当时最新稳定版，验证`soffice.exe`后再继续；安装失败即停止，不得伪造DOCX交付。

## 3. 推荐任务提示

向其他模型发出任务时至少包含：

```text
请加载“土壤三普专业报告撰写与审查”技能的全部必读文件。
先根据封面、行政区范围、统计单元和数据来源判定本报告属于省级、市级还是县级，并执行对应的汇总、比较、篇幅和验收规则。
以我指定的原始底稿为唯一修订基础，逐段审查文字、表格和图件。
正文必须是可直接送审和归档的正式专业报告；审稿意见只能放入批注。
保持用户指定的一、二级标题及特殊编号不变，新增标题不得机械照搬旧导引。
按技能规定控制每小节段数、单段字数和报告总字数。
先列出本次约束和内容任务矩阵，再执行修订；完成后检查接受修订文本、修订批注、禁用表达、表图关系和全部页面版式。
凡输出DOCX，严格执行`references/report-format-requirements.md`的页面、页码、字体、标题、自动目录、题注、图片、表格、缩进和样式清理规则；正文图表编号嵌入说明段的实质性结果句，说明段置于图表之前，图表块前后各空一行；表格框线采用文档通用黑色单实线，不另行指定特殊磅值。遇到大面积空白应调整图表与说明段位置或分页属性，但不得让图表远离主要描述分析段。
逐项检查带圈序号后的半角空格、单位符号、上下标、小数位数和规定保留的末尾`0`；不得只检查文字内容。
```

## 4. 工具差异

Windows环境没有LibreOffice时，先运行技能附带的`ensure_libreoffice.ps1`自动安装最新稳定版。只有操作系统、权限或网络条件使安装失败，且无法使用OOXML编辑工具时，模型才只能输出审查清单和逐段修订文本，并明确说明未生成真实修订模式DOCX。具备文档工具时，必须实际检查修订对象、批注锚点、外部关系和全页渲染结果。

## 5. 结果判定

模型交付前必须能够回答：

- 最终文件是否直接来自原稿？
- 是否正确识别省级、市级或县级，且没有混用其他层级的行政称谓、统计单元和篇幅要求？
- 正文是否还含写给作者的指令？
- 每个结论是否有原稿数据或明确事实支撑？
- 每个小节是否有清楚的段落功能？
- 标题是否符合必要层级，而非模板堆叠？
- 带圈序号、单位符号、上下标和小数位数是否符合强制排版基准？
- 是否满足当前成果层级和报告类型的总字数？
- 是否实际完成修订、批注和逐页版面检查？

不能给出证据时，不得以“已全面检查”“已通过验收”等措辞交付。
