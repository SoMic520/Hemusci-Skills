# 排版审查边界

## 总原则

本 skill 只回答两个问题：稿件的形式是否符合目标期刊当前明确要求；能否在不改变科研内容的前提下修正形式。

如果一个问题需要判断“内容对不对、好不好、够不够”，它就不属于本 skill。

## 允许审查与修订

| 对象 | 可检查 | 可修订 |
|---|---|---|
| 文件 | 文件类型、命名、必需文件是否存在、题名页是否分离 | 重命名副本、组织已有独立文件；不自动跨文件搬运正文 |
| 页面 | 纸张、方向、边距、分栏、分节、页码、行号 | 调整页面和节属性 |
| 文字外观 | 字体、字号、颜色、粗斜体、上下标现状、行距、段距、缩进、对齐 | 调整低风险格式属性；自动创建/取消上下标属于禁区 |
| 标题 | 层级、编号形式、样式、间距、换页 | 映射到规定样式；不改标题文字 |
| 摘要/关键词 | 是否存在、标签、位置、规定数量或机械字数 | 调整标签外观和位置；不改内容 |
| 图 | 文件格式、分辨率、物理尺寸、位置、环绕、题注版式、编号形式 | 调整尺寸/布局；默认不重采样、不改图像像素 |
| 表 | 表宽、边框、表头重复、跨页、对齐、字体、题注版式 | 调整表格属性；不改任何单元格文字或数值 |
| 参考文献 | 编号/作者年形态、段落版式、悬挂缩进、字体、行距、机械顺序形式 | 调整段落和编号格式；不改著录内容 |
| 声明 | 规定栏目是否存在、标签和位置 | 移动原文、调整格式；不补写或判断真实性 |
| 双盲 | 作者信息是否出现在匿名稿、题名页是否独立 | 本包只检查和批注；无跨文件守恒工具时不自动拆分或移动 |

## 禁止审查或修改

- 论文质量、创新性、意义、选题价值、可发表性和录用概率；
- 研究设计、采样、实验、方法选择、统计、模型、结果和结论；
- 事实、数值、单位含义、有效数字、类别、范围和因果方向；
- 语言质量、语法、逻辑、语体、去 AI 痕迹、翻译和摘要质量；
- 引文真实性、参考文献正确性、相关性、完整性和 DOI 是否真实；
- 作者资格、顺序、贡献、基金、伦理、利益冲突和数据声明的真实性；
- 图表是否科学、是否误导、数据是否一致、配色是否适合解释结果；
- 期刊质量、核心身份、分区、星级、影响因子和投稿推荐。

## 边界案例

- “摘要不超过 250 词”可机械计数；“摘要没有突出创新点”属于内容评价，禁止。
- “图宽应为 85 mm”可修订；“图 2 不能支持结论”属于科学评价，禁止。
- “参考文献采用顺序编码制”可调整编号样式；“这篇文献不相关”属于内容评价，禁止。
- “单位符号应使用正体”可调整字形；把 `mg kg−1` 改成另一计量口径可能改变含义，禁止。
- 上标/下标只可检查已有状态；自动添加或取消可能改变化学式、单位或脚注含义，禁止。
- “需要数据可用性声明”可提示缺项；不得替作者编造声明。
- “英文关键词 3–6 个”可计数；不得替作者新增、删除或翻译关键词。

## 越界处理

发现越界问题时：

1. 不修改原稿；
2. 不在 Word 批注中夹带质量评价；
3. 在审查报告的“未执行项目”中写 `OUT_OF_SCOPE_CONTENT_REVIEW`；
4. 简述为何该问题需要作者或学科审稿人判断。
