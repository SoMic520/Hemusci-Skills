# 设计参考与落实证据

本 skill 已实际获取并核对用户指定的 `https://hemusci.com/skills/#principles`。获取时间、HTTP 元数据、响应大小、SHA-256、仓库源文件哈希和原则原文保存在 `hemusci-principles-snapshot-20260815.md`，不是仅凭记忆转述。

## 三条原则如何落到本 skill

### 事实优先

- 所有 DOCX 输出都经过可见文本、脚注/尾注引用映射、域指令、修订历史、公式结构、表格结构、关系映射和不透明包部件校验。
- 自动操作必须绑定原稿 SHA-256、目标段落/表格/分节指纹和已经验证的期刊规则。
- 上下标、域、符号字体、私用区字符等可能改变科研含义的自动操作直接拒绝。

### 领域约束

- 本 skill 的领域是“土壤相关期刊投稿形式”，而不是土壤论文内容质量。
- 规则类别采用排版白名单；中英文越界字段和评论文本由集中策略校验。
- `VERIFIED`、`INFERRED`、`UNVERIFIED` 分开处理，只有带官方来源快照和哈希的 `VERIFIED/AUTO_FIX` 规则可以自动修订。
- 禁词检查只是软件闸门；工作流仍要求把每个判断还原为可观察格式、规则来源和机械动作。

### 真实交付

- 输出分为原稿副本、格式修订清洁版、真实 Word 批注版、规则来源、发现项、操作计划、修改台账和审查报告。
- 批注必须同时具有 `comments.xml`、关系、内容类型、唯一锚点和引用；计数不能代替结构验证。
- LibreOffice/Poppler 渲染只产生 `RENDERED_NOT_REVIEWED`；检查完每一页并签署回执后才可记为 `VISUAL_REVIEW_PASS`。
- 总验收交叉核对规则、发现项、操作、批注、台账、字体、脚注、渲染页和文件哈希，失败时不得宣称完成。

## 继承与排除

Hemusci 页面把 `soil-third-survey-report` 作为已发布示例。本 skill 只吸收“事实、领域、交付”三条公开设计原则和可归档交付思路；不继承三普报告的内容审查、语言润色、固定版式、质量判断或专业结论规则。

期刊排版数值只能来自目标期刊当前官方来源，不能来自示例 skill、目录、记忆或第三方投稿网站。
