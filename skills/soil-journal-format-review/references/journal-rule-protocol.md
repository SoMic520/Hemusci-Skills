# 期刊格式规则获取协议

## 来源要求

只把下列来源视为可执行规则：

1. 用户提供的编辑部通知、返修通知或录用后排版要求；
2. 期刊官网或出版方官网的当前模板；
3. 期刊官网或出版方官网的当前作者指南、投稿须知、检查表；
4. 明确由期刊引用的现行标准。

第三方期刊导航、投稿经验、培训课件、搜索摘要和旧模板只能帮助发现官方页面，不能直接成为规则。

## 版本记录

每次任务记录：

- 期刊全名与 ISSN（可得时）；
- 文章类型和投稿阶段；
- 来源标题、URL、发布日期/版本号和访问日期；
- 本地保存文件名与 SHA-256；`VERIFIED`/`INFERRED` 规则没有快照和哈希时不得执行；
- 规则原文所在章节、页码或页面标题；
- `VERIFIED`、`INFERRED` 或 `UNVERIFIED` 状态。

投稿当天重新打开动态指南。缓存文件是审计证据，不自动代表当前有效。访问时间超过 365 天会触发重新核验警告。

## 冲突解决

按“更具体、更新、离当前投稿阶段更近”的原则处理：

- 编辑部对本稿的通知优先于公开通则；
- 文章类型模板优先于期刊通用指南；
- 期刊指南优先于出版方通则；
- 期刊明确指定的标准版本优先于更晚但未被期刊采用的通用标准；
- 初投稿自由格式不等于返修或录用后仍可自由格式。

每个冲突都要记录被采用规则和未采用规则，不静默覆盖。

## 从近期论文推断

只有官方指南未说明且任务确实需要时，才可从当前官网论文推断可见版式。推断规则必须：

- 至少核对多篇同文章类型论文；
- 标记 `INFERRED`；
- 不覆盖明确官方规则；
- 不用于自动修订或声称强制合规，只能形成批注/待确认项。

## 期刊目录的限制

`journal-registry.csv` 只用于找到官网。它不提供期刊质量结论，也不保证土壤主题适配。是否选择某期刊由作者决定；本 skill 只在目标期刊确定后处理格式。
