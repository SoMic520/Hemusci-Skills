# 已知限制与不得夸大的能力

1. **只完整支持 DOCX**：PDF、LaTeX、Markdown 和扫描件没有本包级自动修改/保真守卫。
2. **不创建跟踪修订**：只生成格式修订清洁版和真实 Word 批注版；已有修订历史必须保留。
3. **脚注/尾注批注 UI**：OOXML 结构可写入和验证，LibreOffice 可渲染正文与脚注版面，但其评论 UI 不能代替桌面 Word。直接锚定 note story 必须经 Word 终检。
4. **双盲拆分**：没有跨多个 DOCX 的内容守恒工具，因此不自动把作者信息移到题名页。
5. **字体下载范围**：自动下载目录只有 Noto Sans SC 和 Noto Serif SC。专有字体缺失时只提供官方获取路径和风险披露。
6. **平台声明**：代码可在 macOS/Windows 运行，不等于两平台都已实测。每个平台必须有自己的工具链、字体和渲染回执。
7. **视觉签署**：哈希可证明检查后图片未改变，不能证明检查者判断一定正确。签署者仍需实际查看所有页面。
8. **来源真实性**：本地快照哈希可证明任务中使用的证据未变，不能单独证明下载时服务器没有被冒充。应使用 HTTPS、官方域名和访问记录。
9. **复杂 OOXML**：宏、ActiveX、altChunk、DDE、危险外链、异常 ZIP 和无法解析的 XML 直接拒绝。未知复杂结构优先失败而不是猜测修复。
10. **应用级往返**：在 Word/LibreOffice 中再次保存可能重写大量 OOXML。任何应用往返后必须重新运行安全、完整性、批注、字体和渲染检查。
