# NAR-1.0 专家自然度零残留协议

## 可保证与不可保证的对象

文本是否曾经由 AI 参与不是一种能从最终字词中无误还原的属性。现有检测方法有误报、漏报、提示或改写敏感性和语言群体偏差：Liang 等报告了对非英语母语写作者的系统性误判，Sadasivan 等从实验与理论上讨论了可靠检测的边界，Kumarage 等展示了检测器对规避性提示的脆弱性：

- <https://doi.org/10.1016/j.patter.2023.100779>
- <https://arxiv.org/abs/2303.11156>
- <https://doi.org/10.18653/v1/2023.findings-emnlp.94>

因此不得保证“文本来源为纯人工”“任意检测器均判为人工”或“永远不可识别”。NAR-1.0 允许保证的对象是：在锁定版本、预先定义的特征目录和指定评审范围内，经独立人工审查后，确认的模板化 AI 写作残留数为零。

## 唯一允许的零残留声明

只有 `assets/naturalness-review-template.json` 的项目副本通过验证，才可使用：

> 在 NAR-1.0 所列审查范围内，对记录哈希的该文本版本，经两名独立评审和必要的分歧裁决，确认的模板化 AI 写作残留数为 0。该结论不证明文本来源、作者身份，也不保证任意检测器均不可检出。

不得删掉第二句，不得把“审查范围内”扩写为普遍结论，不得用“100% 人类写作”“纯人工”“AI 率 0%”替代。

## 特征目录

每项检查整个约定范围，并给出 `absent`、`present` 或 `not_assessable`：

| ID | 残留特征 |
| --- | --- |
| N01 | 聊天开场、协作提示、知识截止说明或模型自述残留 |
| N02 | 无证据的重大意义、宣传性形容和象征性拔高 |
| N03 | “专家认为”“研究表明”等缺少可定位来源的模糊归因 |
| N04 | 空洞的背景—挑战—展望、万能结论或段尾意义句 |
| N05 | 非功能性的三项列举、否定式排比、镜像句和固定段落壳 |
| N06 | 连续段落重复同一开头、句法、节奏或总结模板 |
| N07 | 为避免重复而轮换同义词，造成术语、对象或指代漂移 |
| N08 | 为“更具体”而添加源材料没有的事实、场景、感受或作者个性 |
| N09 | 把观察写成机制、相关写成因果或把局部结果无限外推 |
| N10 | 与论文、基金、专利、标准、报告或海报功能不符的语气和修辞 |
| N11 | 抽象名词、连接词、套话和过度名词化掩盖对象、动作或条件 |
| N12 | 无授权地偏离作者风格表，或机械模仿名家、顶刊和中文“刊物腔” |

单个词、被动语态、破折号、三项事实、第一人称或固定术语本身不是残留。只有结构在当前语境中没有科学、法律、规范或修辞功能时才判为 `present`。

## 审查设计

1. 冻结文本并记录 SHA-256；任何字词变化都使旧审查失效。
2. 预先记录语言、文体、章节、作者风格样本和排除范围。
3. 先完成事实、证据、术语、题材和保护元素审计；不得用自然度审查修补科学问题。
4. 至少两名不同人员独立审查同一哈希版本：一名相关学科学者，一名该语言的科学编辑。两人均不获知文本是否、如何使用过 AI。
5. 两名评审分别对 N01–N12 判定并给出定位。不得先协商答案。
6. 报告原始一致率和每个分歧；可报告 Cohen's kappa，但不得用单一阈值掩盖低发生率造成的统计不稳定。
7. 分歧由第三人裁决。任何 `present`、`not_assessable`、未决分歧或缺失范围均不能得到零残留状态。
8. 修改后重新计算哈希并从第 4 步重审受影响范围；不得沿用旧签字。

## 与作者来源和披露的关系

NAR-1.0 衡量最终文本的可观察质量，不改变真实来源。实际使用过 AI 时，仍按期刊、基金、机构或法律要求披露。伪造人工创作历史、隐藏政策要求的 AI 使用或以自然度审查规避披露，均为硬失败。

## 语料规模不是零残留证明

每模块 1000 篇用于扩大修辞和术语参照面，不能证明新文本无残留。引用名家、模仿顶刊、提高困惑度、随机打乱句长或通过多个检测器都不构成 NAR-1.0 证据。只有锁定文本的逐项独立审查记录才能支持受限声明。
