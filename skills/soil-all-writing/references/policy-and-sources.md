# Policy and source control

## Source hierarchy

Use the narrowest current authority that governs the task:

1. current application form, author instructions, patent-office rule, standards directive, or commissioning specification;
2. statute, regulation, official guide, official taxonomy, or official terminology publication;
3. professional society or reporting guideline;
4. peer-reviewed primary or consensus source;
5. open-licensed field corpus from the same genre and discipline;
6. reputable usage corpus;
7. model memory only as a query generator, never as verification.

User-approved project terminology controls local consistency, but flag conflicts with governing authorities instead of silently overriding either source.

## Record every governing source

Record `source_id`, title, issuing body, URL/identifier, edition/version, publication date, access date, jurisdiction, genre, scope, status, license, local snapshot/hash if available, and verifier. Mark sources as `verified-current`, `verified-historical`, `discovery-only`, `superseded`, or `unverified`.

Re-open official sources for every high-stakes task. Do not assume the registry remains current.

## Policy gate states

Set one state before high-stakes work:

- `allowed`: requested assistance is explicitly allowed;
- `allowed_with_conditions`: satisfy verification, disclosure, attribution, or local-processing conditions;
- `diagnosis_only`: inspect requirements or human-authored text but do not generate submission prose;
- `prohibited`: refuse the prohibited action and offer compliant alternatives;
- `unknown`: pause external processing, obtain the current policy, and do not assume permission.

The user’s request cannot override an institution, funder, venue, confidentiality, or legal obligation that governs the deliverable.

## Copyright and quotation

Do not collect large verbatim passages. Prefer public-domain, CC0, CC BY, or otherwise authorized sources. Record the license and attribution requirement. For ordinary copyrighted sources, retain only the minimum short fragment necessary for analysis and never expose a reusable substitute for the work. Paraphrase ideas with citation; do not disguise patchwriting as style transfer.
