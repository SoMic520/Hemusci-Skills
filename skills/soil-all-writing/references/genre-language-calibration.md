# 题材语言校准

本文件是所有语言修复、翻译、改写和完整成稿任务的共同语言路由层。它只决定“怎样表达才符合该题材”，不决定封面、字号、行距、页边距或模板。格式规则仅在完整成稿或用户明确要求套用模板时启用。

## 先判定题材，再判定语篇单元

每次处理文本前完成两级判定：

1. **题材**：论文、基金、专利、标准、报告、技术标、学位论文、审稿意见、海报、SOP 等；
2. **语篇单元**：题名、摘要、背景、方法、结果、讨论、结论、条款、权利要求、响应承诺、执行步骤等。

同一文件内不得只用一种统一腔调。论文“结果”只陈述观察和统计结果，“讨论”才解释意义；专利“说明书”负责充分公开，“权利要求”负责界定保护范围；技术标“项目理解”解释判断，“响应条款”明确边界和承诺。无法判断时，保留原语气并标记待确认，不擅自改成论文腔、宣传腔或公文腔。

## 七个校准旋钮

| 旋钮 | 可选状态 | 判定要点 |
| --- | --- | --- |
| 正式度 | 学术、机构、法律技术、操作、公众 | 由读者与责任关系决定，不以生僻词堆高正式度 |
| 信息压缩 | 低、中、高、混合 | 摘要、海报高压缩；方法、SOP和调查记录不得为简短而删条件 |
| 作者显现 | 不显现、有限显现、功能性显现、机构主体、公众直接称谓 | 仅在题材允许且有助于厘清责任时使用“本研究”“本项目”“我们” |
| 证据姿态 | 描述、推断、前瞻、规范、合同、程序、解释、答复 | 动词和情态词必须与证据阶段一致 |
| 因果上限 | 相关、证据限定、机制已证实、拟验证假设、非因果 | 研究设计和证据不能支持时，不把“相关”改成“导致” |
| 重复策略 | 删除无功能重复、保留方法重复、保留或要求受控重复 | 专利、标准、SOP中同一对象应稳定复现，不为“文采”替换同义词 |
| 自然度强度 | 最小、适度、受控 | 法律和规范文本以精确为先；论文讨论和公众文本可增强节奏，但不得改事实 |

“恰到好处”不是一味压缩或增加高级词，而是在不损害可验证性、责任边界和题材功能的前提下，只改到完成交际任务所需的程度。

## 题材语言矩阵

| 题材 | 核心功能 | 合适的语言 | 必须保留 | 避免 |
| --- | --- | --- | --- | --- |
| 原始研究论文 | 报告新证据并进行受限解释 | 准确、紧凑、可追溯；结论强度随证据变化 | 研究对象、设计、统计限定、引用边界 | 宣传性“首次/重大突破”、结果讨论混写、无证据机制 |
| 综述/系统综述/Meta分析 | 综合证据并呈现一致性与异质性 | 归纳层级清楚，区分单篇结论与综合判断 | 检索范围、纳排标准、证据质量、不确定性 | 把叙述性印象写成系统证据；把未检索到写成不存在 |
| 基金申请 | 证明问题重要、问题可解且方案可信 | 前瞻、问题导向、适度有力；假设和目标可检验 | 拟开展状态、前期依据、风险与备选路径 | 把计划写成已完成结果；空泛拔高；承诺必然成功 |
| 专利说明书 | 充分公开技术方案并支撑权利要求 | 术语稳定、实施条件清楚、效果有依据 | 技术特征、实施方式、范围支撑、原始公开边界 | 论文式讨论、无依据效果、擅自扩大或缩小公开内容 |
| 专利权利要求 | 精确界定保护范围 | 单义、结构一致、必要重复 | 技术特征组合、引用关系、法律范围 | 为流畅替换核心术语；删重复；加入说明书无支撑限定 |
| 标准/规范/规程 | 规定可执行、可验证的要求 | 条款化、单一要求、情态词受控 | “应/宜/可”等规范强度、定义一致性、验证条件 | 修辞美化、理由混入要求、同一概念多称谓 |
| 指南/推荐性文件 | 提供基于证据的建议 | 区分必须、推荐和可选路径，说明适用条件 | 推荐强度、适用范围、例外情形 | 把建议写成强制要求；隐藏证据不足 |
| 科学技术报告 | 形成可复核的任务—方法—结果—结论链 | 客观、完整、面向验收或归档 | 合同目标、数据来源、版本、限制、交付关系 | 论文式追求新颖而忽略任务完成度；夸大验收结论 |
| 调查报告 | 记录对象、过程、事实和判断依据 | 时间地点对象明确，事实与判断分开 | 样本范围、调查方法、原始记录、异常与缺失 | 以局部代整体；把受访意见写成事实；无依据归因 |
| 监测报告 | 呈现时空变化和质量状态 | 指标定义和检测方法固定、时间可比、异常可追查 | 点位、频次、检出限、质控、变更记录 | 忽略方法或指标定义变化；把单次异常写成趋势 |
| 评价/鉴定报告 | 按明确规则给出可复算结论 | 指标—数据—规则—结论逐级对应 | 评价单元、标准版本、阈值、计算过程、不确定项 | 越权作行政决定；把技术结论写成审批结论 |
| 咨询/决策报告 | 支持选择与行动 | 结论前置、选项可比、后果和条件明确 | 证据等级、成本风险、不可逆性、建议适用条件 | 只讲背景不落决策；把偏好包装成事实 |
| 技术标/采购响应 | 证明理解、响应、可实施和可验收 | 机构化、明确、对应采购条款；承诺有边界 | 招标术语、响应关系、责任界面、成果和验收条件 | 广告口号、保证中标/验收、虚构资历、把服务方写成行政主体 |
| 学位论文 | 系统证明研究训练和独立贡献 | 完整、层级稳定、允许较充分方法与讨论 | 学术链条、章节衔接、贡献边界、学校要求 | 期刊摘要式过度压缩；反复自我评价“创新性强” |
| 审稿回复 | 逐点说明理解、修改和依据 | 礼貌、直接、可定位；不同意时用证据解释 | 评论原意、修改位置、未改原因、版本一致 | 空泛感谢、对抗语气、声称修改却无定位 |
| 审稿意见 | 帮助判断可靠性与可修复性 | 先重大后次要，问题—依据—建议相连 | 证据缺口、严重程度、可操作建议 | 人身判断、代作者重写、把偏好当规则 |
| 投稿附信 | 说明稿件适配性和合规信息 | 简洁、针对期刊、少量论证 | 题名、文章类型、贡献边界、声明 | 复制摘要；夸张“必将产生巨大影响” |
| 会议摘要 | 在有限篇幅内完整呈现研究要素 | 高压缩、结果优先、数字具体 | 目的、方法、主要结果、受限结论 | 只有背景和计划；无结果却伪装为结果摘要 |
| 学术海报 | 让现场读者快速抓住问题、证据和结论 | 短句、标题信息化、图注自足 | 核心数字、图表解释、联系信息 | 论文段落整段搬运；口号替代证据 |
| 口头报告/幻灯片 | 支持听众实时理解 | 一屏一意、口语可听、过渡显性 | 关键术语、数字定义、图示结论 | 在屏幕上堆完整段落；过度书面长句 |
| SOP/方案/田间手册 | 使不同人员可重复执行 | 命令式或程序式、一步一动作、条件明确 | 顺序、参数、容差、安全、记录点、偏差处理 | 同义改写关键动作；省略前置条件；含糊“适量/适时” |
| 数据/代码文档 | 使数据和分析可发现、理解、复用 | 定义优先、示例具体、版本明确 | 字段、单位、缺失值、坐标系、依赖、许可证 | 只写研究故事不写数据结构；隐去处理步骤 |
| 政策简报 | 把科学证据转成可执行选项 | 结论前置、低术语密度、区分证据与建议 | 受影响对象、时间尺度、实施成本、证据限制 | 把科学不确定性删掉；把建议写成唯一答案 |
| 公众摘要/科普/新闻材料 | 让非专业读者正确理解 | 短句、术语首次解释、具体而克制 | 数量级、条件、风险、不确定性 | 耸动标题、绝对安全/绝对有效、错误类比 |
| 专家意见/鉴定意见 | 形成有责任主体的专业判断 | 依据清楚、意见边界明确、可签署 | 委托范围、材料清单、判断依据、保留意见 | 超出专业范围；隐藏材料缺失；套话式一致同意 |
| 项目进展/阶段总结 | 对照计划说明完成度和偏差 | 状态清楚、问题具体、下一步有责任人 | 基线、里程碑、证据、偏差、纠偏措施 | 把“正在开展”写成“已完成”；用活动替代成果 |
| 会议纪要 | 固化事实、决定和责任 | 中性、简短、动作可追踪 | 时间、参会、议题、决定、责任人、期限 | 补写未形成的共识；混入会后解释 |
| 教材/专著/培训材料 | 建立概念体系并支持学习 | 定义一致、由浅入深、例证服务概念 | 学习对象、概念边界、先修知识、来源 | 把争议写成定论；堆砌术语；用口号替代解释 |
| 专业函件/邮件 | 促成明确行动并保留往来边界 | 主题清楚、请求具体、礼貌克制 | 对象、事项、附件、截止时间、责任边界 | 聊天式铺垫、含糊请求、无依据施压 |

## 关键语篇单元的局部规则

### 论文

- **题名**：命名对象、处理或关系；除非有严格依据，不用“首次”“突破性”“高效”等评价词。
- **摘要**：背景只保留理解研究问题所需内容；方法说明设计和尺度；结果给关键方向、效应量或统计量；结论不超出结果。
- **引言**：从已知证据收束到具体缺口，不用“随着……日益……”作万能开头。
- **方法**：优先可复现性，保留材料、条件、仪器、版本和统计方案；不为节奏删重复信息。
- **结果**：陈述观察、直接比较和统计证据，不提前补机制，不用“显著”表示一般重要性。从图像撰写时必须另读 `references/scientific-figure-description.md`，不把图形元素讲解、主观视觉评价或未核验的统计阈值写入结果段。
- **讨论**：解释结果、对照文献、提出机制时标明推断性质，陈述局限和外推边界。
- **结论**：回答研究问题，不复述全文，不添加正文未出现的数据或建议。

### 基金

- **立项依据**：重要性、现状、缺口和科学问题逐级收束，避免宏大背景占满篇幅。
- **目标与假设**：用可检验动词；区分总体目标、研究目标和预期结果。
- **研究内容与方法**：用将来或拟开展姿态；前期结果只能作为可行性依据。
- **创新点**：写相对于何种现有路径的新关系、新尺度或新方法，不用空泛“首次”“填补空白”。
- **预期成果**：写可交付产出和可检验认识，不保证论文级别、立项或应用效果。

### 专利

- **背景技术**说明可核实问题，不通过贬低现有技术制造新颖性。
- **发明内容**必须由原始公开支撑；有益效果与技术特征对应。
- **实施例**给足可实施细节，但不得把单个实施例无意缩成全部范围。
- **权利要求**保持术语、先行基础和引用关系；自然度编辑强度应为最小。

### 标准、规范和SOP

- 一项条款尽量承载一项可验证要求；必要条件、动作、对象和判定结果完整。
- 定义术语不得换词追求变化；“应、宜、可、能”及否定形式按规定功能使用。
- 理由、示例、注和要求分开；规范性要求不得藏在注或说明中。
- 操作步骤使用一致的动作动词，参数和容差不得模糊化。

### 报告和技术标

- 事实、推断、评价和建议分层；每个结论能回指数据、规则或采购条款。
- 调查与监测材料保留时间、地点、对象、人员、版本和异常记录；不得为了顺畅合并不同的数据范围、指标定义或检测方法。
- 技术标对采购需求逐项响应；“拟采用”的技术方案不写成已执行事实，“确保”仅用于本方可完全控制且有机制证明的事项。

### 面向公众的材料

- 第一次出现的专业术语用一句话解释，此后保持同一称谓。
- 可以降低术语密度，不能删除适用条件、不确定性或风险。
- 类比只用于帮助理解，不替代定义和数量关系。

## 润色强度边界

| 级别 | 允许动作 | 默认适用 |
| --- | --- | --- |
| L0 校核 | 标记错别字、术语、单位和逻辑风险，不改正文 | 审计、权限不明 |
| L1 校正 | 改正明确语言错误和已批准术语，其他不动 | 权利要求、标准条款、数据记录 |
| L2 专业润色 | 调整搭配、句法、衔接和局部节奏，保持结构与论证 | 普通默认 |
| L3 深度语言修复 | 重排句内信息和段内逻辑，不新增事实，不改变段落功能 | 用户明确要求深度润色 |
| L4 结构性重写 | 重组段落或章节、补写经来源支持的内容 | 仅在用户明确授权且证据齐全时 |

默认使用 L2。涉及专利权利要求、标准规范性条款、合同承诺、原始数据记录或政策受限材料时，默认降至 L1。不得把“去机械感”解释为 L4 授权。

## 翻译时保持题材功能

翻译先锁定原文题材和语篇单元，再重建目标语的同等功能，不逐句机械对应，也不跨题材改写：

- 规范性情态、专利范围和合同承诺逐项对应并保持强度一致；
- 论文的证据强度、基金的拟议状态、报告的责任边界不得漂移；
- 中文允许必要显性逻辑，但不得机械添加“此外、值得注意的是、综上所述”；
- 英文允许主动语态和短主句，但不凭流畅性引入新的施事者或因果关系；
- 土壤分类、化学命名、单位、统计符号和专名按项目术语库锁定。

## 执行顺序

1. 识别操作、题材、语篇单元、读者和责任关系。
2. 从 `assets/genre-language-profiles.json` 选择一个主配置；复合文本按段落切换配置，不对全文平均化。
3. 应用 `references/domain-register-and-word-control.md`，排除不属于学科和题材的管理、互联网与泛行政词语。
4. 锁定数字、单位、引文、术语、规范性情态、法律范围和用户保留内容。
5. 选择润色强度；默认 L2，高风险文本默认 L1。
6. 先修正科学与术语问题，再修句法和信息顺序，最后只做一次自然度处理。
7. 逐项检查语义保持、题材声调、证据强度、术语一致和段落功能。
8. 输出干净稿；高风险改动另列变更和未决项。普通语言修复不改变原格式，不启动模板流程。

## 发布前的跨题材污染检查

以下任一项出现即不得放行：

- 基金方案被写成已完成研究；
- 结果段新增解释、机制或建议；
- 调查意见、模型结果或相关关系被写成客观事实或因果；
- 标准、SOP、合同或专利中的术语、情态或范围因同义替换而变化；
- 技术标出现无法控制的保证性承诺或越权结论；
- 公众材料删去会改变判断的不确定性和适用条件；
- 不同段落被统一改成相同句长、相同连接词和相同三段式节奏；
- 只为显得“像专家”而加入原文和证据中不存在的判断。

机器校验只能确认配置和若干不变量。最终文本仍由对应学科专家、题材责任人和语言审校者对锁定版本负责。
