## 路由优先级

1. 本 Skill 先完成文体、权威、篇幅、模板、封面、术语、证据强度和发布合同。
2. 当任务真正包含方法选择、统计计算、GIS 分析或受控平台写入时，只在用户授权且不得自行伪造时调用专门能力。
3. 中文技术标运行时不调用其他写作或格式 Skill；本 Skill 直接生成、校验、渲染和签核。
4. 任何外部能力都不得改写本 Skill 锁定的事实、术语、法律边界、规范性强度或受控格式。

## 仍需本 Skill 独立承担的空白

- 中文与英文土壤科学概念级 termbase；
- 顶刊、中文高质量期刊和专家第一作者语料的许可化提炼；
- 基金、专利、标准、报告、调查、论文、审稿、海报及日常科研载体的语言路由；
- 证据强度与规范性/法律语气保护；
- 十类模型/平台的能力 profile、降级和资格矩阵；
- 受保护元素、语料、术语、项目清单和跨模型资格的确定性审计。

因此 `soil-all-writing` 是“土壤学专业写作 + 文体合同 + 受控格式 + 可验证交付”的统一层，不是 Humanizer 的加长词表，也不伪装成方法学、统计、实验或法定审批系统。
