# 中文土壤科学完整文档生成的格式、篇幅、模板与封面注册表

本文件只服务于“完整文档生成”、“按指定模板整改”或“生成可直接使用的格式化成品”。它不是普通语言润色的前置条件，也不是把所有文体套入同一个 Word 模板。用户只要求语言精修、术语纠正、翻译对齐或去机械化表达时，默认保留原格式，不检索、不选择、不套用模板。

进入完整文档生成模式后，必须建立 `genre output contract`，指明当前文体、控制文件、篇幅口径、模板、封面、页面几何、提交文件与释放门槛。用户提供的模板优先于官方公开模板，当前任务的官方受控文件优先于 Skill 默认版式。

## 1. 权威层级

从高到低依次为：

1. 当前任务的受控模板、网上填报系统、招标文件、补遗、答疑和编辑部指令；
2. 适用法律法规、部门规章、强制性标准和有权机构当年指南；
3. 当前有效的国家/行业/地方标准及单位制度；
4. 目标期刊、会议、学校或委托方的最新公开说明；
5. 本 Skill 的内部起草预算和默认格式。

下位规则不得覆盖上位规则。不得把“常见”、“建议”或其他 Skill 的默认值改写为“必须”。

## 2. 篇幅合同

每个篇幅条目必须同时记录：

- `limit_state`：`controlled`、`venue_controlled`、`no_universal_limit` 或 `controlled_source_missing`；
- `limit_type`：`hard`、`recommended`、`system_enforced` 或 `internal_drafting_budget`；
- `count_unit`：包含标点的中文字符、不含标点的中文字符、英文单词、页、幅/张、分钟、条款、图表数或文件字节；
- 上限/下限、计数范围、不计入项、超限处理；
- 来源名称、版本/年度、URL、定位、获取日期和适用范围。

存在页数限制时，页面尺寸、页边距、字体与字号是限制的一部分，不得通过缩小字号、压缩行距或图表文字规避页限。存在字数限制时，计数器必须与系统口径一致；口径不明时不得声称“已通过”。

## 3. 文体注册表

| 文体 | 当前中文场景的一般控制源 | 篇幅状态 | 模板与封面规则 |
| --- | --- | --- | --- |
| 研究论文、短报、述评/观点、方法论文 | 目标期刊当前作者指南与文章类型；GB/T 7713.2—2022 可作学术论文编写基线 | 无跨期刊通用字数或页数；必须标为 `venue_controlled` | 期刊要求书控制；通常不自制装饰封面，按要求提交标题页、匿名稿或分文件 |
| 综述、系统综述、范围综述、元分析 | 期刊类型说明 + 适用报告指南 | 无通用上限；摘要结构、图表和附录由期刊/指南控制 | 不得用叙述性综述模板伪装系统综述 |
| 数据论文/数据说明 | 目标数据期刊；GB/T 7713.4—2025 | 无通用字数；必须保留字段、质量、访问和复用要求 | 期刊模板控制，不自制封面 |
| 学位论文 | 授予单位当年写作规范、学位系统；GB/T 7713.1—2025 | 无全国通用字数；学校可控制页数、摘要、参考文献和附件 | 使用学校最新 Word/LaTeX 模板和标准封面，不自设校徽、编号或密级 |
| 参考文献 | 目标载体说明；GB/T 7714—2025 已于 2026-07-01 实施并全部代替 2015 版 | 无通用篇数上限；期刊/项目类型可限制 | 文内标注制、顺序和著录格式由载体控制，不用旧版默认覆盖新规则 |
| NSFC 面上项目、青年科学基金项目（C 类） | NSFC 2026 申请通告、当年系统模板和项目指南 | 2026 年正文原则上不超过 30 页；主要为立项依据、研究内容、研究基础三部分 | 系统生成封面与申请书；禁止自制封面；其他项目类型不类推 30 页 |
| 其他科研项目/基金申报 | 资助方指南、当年申报系统和单位通知 | `venue_controlled`；各栏字数可由系统强制 | 只使用系统/官方模板和封面 |
| 中国发明/实用新型专利申请 | CNIPA 现行请求书、审查指南及修改决定 | 说明书和权利要求无简单通用字数；说明书摘要文字部分包括标点符号不得超过 300 个字 | 必须使用 CNIPA 当期请求类表格和文件形式；禁止宣传性封面 |
| 国家/行业/地方/团体/企业标准、技术规程 | 发布机构和对应层级的起草规则；国家标准参照 GB/T 1.1—2020 | 无通用字数；条款数由范围和可验证要求决定 | 使用发布/立项机构的前封面、编号和版式；不自行生成正式标准号 |
| 科技/研究/技术报告 | 合同、任务书、单位模板；GB/T 7713.3—2014 | 无通用字数；合同或委托方可控制页数 | 黑白正式题名页：报告名、报告类型、委托/承担单位、编制单位、日期、版本、密级（如适用） |
| 调查、监测、评价、咨询、验收、阶段/结题报告 | 委托合同、主管部门规程、单位模板和数据标准 | 无通用字数；成果清单、图件、附件可有硬限制 | 使用委托方模板；无模板时用正式黑白题名页，不用彩色卡片或装饰边框 |
| 政府采购技术标/招标响应文件 | 招标文件、补遗、答疑、评分办法、电子交易系统 | 不存在全国通用字数/页数；必须显式响应招标文件 | 受控模板不得删改实质性格式文字；无模板时采用纯黑白封面，不用底纹、色带、卡片或信息方框 |
| SOP、实验协议、野外手册、数据/代码文档 | 实验室/质量体系/仓库模板 | 无通用字数；步骤数和复现信息不得为压缩而删除 | 使用版本、编号、批准、生效日期和修订记录页；不伪造批准人 |
| 学术海报 | 会议/主办方模板、画布尺寸和文件限制 | 无通用字数；内部字数预算必须在尺寸、观看距离和图表占比确定后建立 | 主办方模板控制；不把论文缩小字号后塞入海报 |
| 口头报告/幻灯片 | 会议时长、屏幕比例、主办方或单位模板 | 无通用页数；以时长、口播速度和问答余量计算，不把“6×6”当强制规则 | 优先使用会议/单位母版；无模板时用低密度、可读层级和可追溯来源 |
| 会议摘要/扩展摘要 | 征文通知与提交系统 | 通常有字数/页数/图表/文件大小硬限，但无通用值 | 使用征文模板；标题、作者、单位和关键词格式不自行改动 |
| 审稿回复、投稿信、学术邮件 | 期刊系统、编辑部指令、机构邮件规范 | 无通用字数；投稿信“1 页”只能作为无受控规则时的内部精简目标 | 审稿回复用评论—回复—修改位置结构；投稿信不需装饰封面 |
| 政策简报、通俗摘要、新闻稿、专家意见、咨询备忘录 | 发布单位、委托方和读者任务 | 无通用字数；必须在不删除关键证据和不确定性的前提下定预算 | 用单位模板；标题页/抬头是否需要由真实用途决定 |
| 培训讲义、教材、专著章节 | 出版社/培训单位模板与读者层级 | 无通用字数；章节长度与学习目标、例题和练习匹配 | 出版/课程模板控制，封面图像和版权信息需单独授权 |

## 4. 中文土壤学期刊的官方样例

这些数值只对注明的期刊、页面和文章类型有效，不向其他期刊类推。

- 《土壤学报》官方首页当前提示中文摘要约 250 字、英文摘要约 650 字，并实行双向匿名；实际投稿时必须再核对当前稿件模板和文章类型：<https://trxb.ndhx.net/>。
- 《植物营养与肥料学报》官方基本信息页提示题名一般不超过 20 个汉字，中英文摘要须保留较完整的研究信息；该刊 2025 年官方论文 PDF 中载有中文摘要 800—1000 字、A4、正文五号宋体和三线表等投稿说明；该 PDF 是特定时点例证，不得代替当前模板：<https://edit.plantnutrifert.org/journalx_zwyy/basicinfo/viewHtmlFile.action?id=8>、<https://www.plantnutrifert.org/fileZWYYYFLXB/journal/article/zwyyyflxb/2025/1/2189620d-23b8-4773-bbdf-5434aa4748c4.pdf>。
- 《土壤通报》官方投稿页要求下载现行格式模板；未取得模板快照时，不写死字数和格式：<https://trtb.cbpt.cnki.net/EditorB3N/PromptPageInfo.aspx?c=1&t=v>。
- 《中国土壤与肥料》的期刊身份和发布单位可从中国农业科学院官方期刊页核实；具体投稿限制仍以该刊当前编辑系统为准：<https://www.caas.cn/xxfw/zyfw/cqk/81791d9be9304b7dbef8b97aaf9b2e6b.htm>。

## 5. 封面配置

| 配置 | 适用 | 必备字段 | 禁止项 |
| --- | --- | --- | --- |
| `controlled_template` | 基金、专利、标准、招标、学位论文和有指定模板的任务 | 由模板字段清单决定 | 删改实质性文字、自造编号/标志/公章/密级 |
| `formal_black_white` | 无受控模板的报告或技术标底稿 | 题名、文件类型、项目编号、委托/投标/编制单位、责任人字段、日期，必要时版本与密级 | 彩色底纹、色带、渐变、卡片、装饰边框、用表格框住封面元数据 |
| `title_page_only` | 期刊、书稿、部分编辑流程 | 由期刊/出版社决定 | 把宣传海报当学术题名页 |
| `none` | 审稿回复、投稿信、学术邮件等 | 不适用 | 无功能封面 |
| `poster_or_slide_master` | 海报和演示 | 主办方/单位规定 | 未授权商标、伪造机构形象、低对比度和不可读小字 |

## 6. 模板生命周期

模板注册项必须含有：机构、文体/文章类型、地区、年度或版本、官方 URL、下载日期、本地快照路径、SHA-256、状态、适用范围、预计复核日期与重新抓取触发器。以下任一条件发生时必须复核：

- 申报/投稿/投标年度变化；
- 官方页面标注更新、模板文件哈希变化或 URL 跳转；
- 标准状态改为修订、替代、废止或过渡；
- 期刊变更文章类型、匿名要求或网上表单；
- 用户提供的受控文件与注册表冲突。

对受控文件的事实内容和结构/样式权限分别判定。旧项目文件可以作样式参考，不自动授权其中的人名、机构、项目号、数据、业绩、链接和结论。

## 7. 发布失败条件

任一条件成立时，不得声称格式已通过：

- 硬限制没有官方来源或来源无定位；
- 计数单位不明、本地计数与系统计数不一致；
- 受控模板已失效、未取得或哈希未锁定；
- 正式版仍有占位符、过期要求、旧版标准或参考项目残留；
- 为压缩篇幅而低于受控模板的最小字号、行距或页边距；
- 封面、页眉、页码、附件索引、目录或表格跨页没有经过实际渲染检查。
